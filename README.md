A Next.js 16 application scaffolded with **[Lyzr's Architect](https://lyzr.ai)** — a git-native AgenticOS build with a Postgres ledger backend and a Radix/shadcn frontend.

> **Status: prototype.** The name is auto-generated by Lyzr's Architect; treat this as an early experiment rather than a shipped product.

## Stack

- **Framework:** Next.js 16 (webpack build, port `3333`)
- **UI:** Tailwind CSS + shadcn/ui + Radix primitives (accordion, dialog, dropdown-menu, hover-card, menubar, navigation-menu, and the rest of the shadcn set)
- **Data:** Drizzle ORM + `lyzr-pg-migrate` for schema migrations (Postgres)
- **Deploy target:** Netlify (`netlify.toml`) + Docker (`Dockerfile` + `docker-entrypoint.sh`)
- **Agent framework:** `@open-gitagent/gitagent` — git-native agent runtime
- **Forms:** `@hookform/resolvers`
- **Icons:** `lucide-react` only (React-icons banned per `AGENTS.md`)

## Running locally

**Prerequisites:** Node.js 18+, PostgreSQL (if you want a live ledger; the app boots without one for UI-only work)

```bash
git clone https://github.com/madhusudanpatnaik/insight-ledger-ultra-spark-scsf
cd insight-ledger-ultra-spark-scsf
npm install

# Optional — set a database URL to enable migrations + persistence
export DATABASE_URL="postgres://user:pass@host:5432/dbname"

npm run dev    # → http://localhost:3333
```

`npm run predev` auto-runs `lyzr-pg-migrate` when `DATABASE_URL` is set.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Next dev server on `:3333` |
| `npm run build` | Production Next build (webpack) |

| `npm run db:generate` | Drizzle: generate migrations from schema |
| `npm run db:migrate` | Apply migrations via `lyzr-pg-migrate` |

## Deploy

**Netlify:** connect the repo — the included `netlify.toml` handles it.

**Docker:**

```bash
docker build -t insight-ledger .
docker run -p 3333:3333 -e DATABASE_URL="..." insight-ledger
```
